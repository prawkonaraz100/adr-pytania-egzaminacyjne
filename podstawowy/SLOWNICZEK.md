# Słowniczek ADR dla kursanta

Proste objaśnienia pojęć spotykanych w lekcjach i pytaniach. Definicje pomagają zrozumieć materiał, ale nie zastępują pełnego wpisu ADR dla konkretnego towaru. Gdy przewóz zależy od liczby, rodzaju opakowania lub postaci towaru, sprawdź dokładne warunki w tabeli A i wskazanym punkcie ADR.

| Pojęcie | Co to znaczy po ludzku? | Gdzie sprawdzić |
|---|---|---|
| **ADR** <a id="adr"></a> | Umowa i przepisy określające warunki drogowego przewozu towarów niebezpiecznych. | ADR, załączniki A i B |
| **Numer UN** <a id="numer-un"></a> | Czterocyfrowy identyfikator pozycji towaru niebezpiecznego. Pomaga znaleźć właściwy wpis i nazwę przewozową; sam numer nie opisuje wszystkich warunków przewozu. | ADR 3.2, tabela A, kolumna 1 |
| **Nazwa przewozowa** <a id="nazwa-przewozowa"></a> | Ustalona w ADR nazwa, którą wpisuje się w dokument przewozowy. Nie zawsze jest taka sama jak nazwa handlowa produktu. | ADR 3.2, tabela A, kolumna 2; 5.4.1 |
| **Klasa zagrożenia** <a id="klasa-zagrozenia"></a> | Grupa opisująca główny rodzaj niebezpieczeństwa, np. gazy, ciecze zapalne lub materiały żrące. | ADR część 2; tabela A, kolumna 3a |
| **Grupa pakowania** <a id="grupa-pakowania"></a> | Oznaczenie stopnia zagrożenia dla klas, w których grupy pakowania mają zastosowanie. Nie występuje dla każdego towaru i nie wolno przypisywać jej na chybił trafił. | ADR 2.1.1.3; tabela A, kolumna 4 |
| **Nalepka ostrzegawcza** <a id="nalepka-ostrzegawcza"></a> | Znak w kształcie rombu, który wskazuje rodzaj zagrożenia. Nie zastępuje numeru UN ani pozostałych wymaganych oznaczeń. | ADR 5.2.2 |
| **Tablica pomarańczowa** <a id="tablica-pomaranczowa"></a> | Tablica na pojeździe używana w sytuacjach określonych ADR. Jeśli jest numerowana, górny numer oznacza zagrożenie, a dolny numer UN. Nie każdy przewóz wymaga takiej samej konfiguracji. | ADR 5.3.2 |
| **Numer rozpoznawczy zagrożenia** <a id="numer-rozpoznawczy-zagrozenia"></a> | Numer umieszczony u góry numerowanej tablicy pomarańczowej; opisuje rodzaj zagrożenia według systemu ADR. Nie jest numerem UN. | ADR 5.3.2.3 |
| **LQ — ilości ograniczone** <a id="lq-ilosci-ograniczone"></a> | Uproszczony sposób przewozu niektórych towarów w małych opakowaniach wewnętrznych, jeżeli spełniono limit i wszystkie warunki pakowania oraz oznakowania. Sam znak LQ nie zwalnia z tych warunków. | ADR 3.4; tabela A, kolumna 7a |
| **EQ — ilości wyłączone** <a id="eq-ilosci-wylaczone"></a> | Odrębny mechanizm dla bardzo małych ilości, z własnymi limitami, wymaganiami pakowania, oznakowania i dokumentacji. EQ nie jest tym samym co LQ. | ADR 3.5; tabela A, kolumna 7b |
| **ADR 1.1.3.6 — wyłączenie ilościowe** <a id="adr-1-1-3-6-wylaczenie-ilosciowe"></a> | Zasady, które w określonych przewozach pozwalają skorzystać z częściowych wyłączeń, gdy spełniono warunki i prawidłowo obliczono ilości według kategorii transportowych. To nie jest automatyczne zwolnienie z całego ADR. | ADR 1.1.3.6.3–1.1.3.6.5; tabela A, kolumna 15 |
| **Kod E0** <a id="kod-e0"></a> | W tabeli A oznacza brak możliwości skorzystania z wyłączenia EQ dla danej pozycji. Nie oznacza „zero ryzyka” ani nie daje limitu na opakowanie. | ADR 3.5; tabela A, kolumna 7b |
| **Kod ograniczenia przejazdu przez tunele** <a id="kod-ograniczenia-przejazdu-przez-tunele"></a> | Kod przypisany towarowi, który pomaga ustalić, czy można przejechać przez tunel danej kategorii. Trzeba uwzględnić kod całego ładunku i postać przewozu. | ADR 3.2, tabela A, kolumna 15; 8.6 |
| **Kategoria tunelu A–E** <a id="kategoria-tunelu-a-e"></a> | Oznaczenie ograniczeń dla przewozu towarów niebezpiecznych w tunelu. Porównuje się ją z kodem tunelowym ładunku; nie wybiera się trasy tylko według jej długości. | ADR 8.6.3–8.6.4 |
| **DMC** <a id="dmc"></a> | Dopuszczalna masa całkowita pojazdu — maksymalna masa pojazdu wraz z ładunkiem, określona w dokumentach pojazdu. Może wpływać na wymagania dotyczące wyposażenia. | Dokumenty pojazdu; w kontekście ADR m.in. 8.1.4 |
| **Jednostka transportowa** <a id="jednostka-transportowa"></a> | W ADR jest to pojazd silnikowy wraz z połączoną z nim przyczepą lub naczepą, gdy tworzą zestaw. To ważne m.in. przy ustalaniu ilości przewożonych towarów i wymaganego wyposażenia. | ADR 1.2.1 |
| **Opakowanie zbiorcze (OVERPACK)** <a id="opakowanie-zbiorcze-overpack"></a> | Osłona lub opakowanie użyte do zebrania kilku sztuk przesyłek, np. dla łatwiejszej obsługi. Jeśli zasłania wymagane oznaczenia, trzeba zastosować właściwe dodatkowe oznakowanie. | ADR 1.2.1; 3.4.11; 3.5.4.3 |
| **Instrukcje pisemne** <a id="instrukcje-pisemne"></a> | Ustandaryzowane wskazówki dla załogi, co robić w zdarzeniu. Muszą być dostępne w kabinie i zrozumiałe dla każdego członka załogi. | ADR 5.4.3 |
| **Przewóz luzem** <a id="przewoz-luzem"></a> | Przewóz towaru bez sztuk przesyłek, tylko gdy ADR dopuszcza taki sposób i spełniono wymagania wobec pojazdu lub kontenera. Nie oznacza dowolnego wysypania towaru do pojazdu. | ADR 7.3; tabela A |
| **Kod tunelowy D/E** <a id="kod-tunelowy-d-e"></a> | Zapis, którego zastosowanie zależy od postaci przewozu. Dla cystern i sztuk przesyłek ograniczenie może działać inaczej, dlatego sprawdź regułę ADR dla konkretnej sytuacji. | ADR 3.2, tabela A, kolumna 15; 8.6.3.1 |
| **Masa brutto sztuki przesyłki** <a id="masa-brutto-sztuki-przesylki"></a> | Masa całego opakowania wraz z zawartością i elementami opakowania. Nie jest to sama masa substancji. | ADR 3.4 i właściwe przepisy pakowania |
| **Słowo „ODPAD”** <a id="slowo-odpad"></a> | Dopisek w określonych dokumentach, który informuje, że towar niebezpieczny jest odpadem. Nie zastępuje prawidłowej nazwy przewozowej ani numeru UN. | ADR 5.4.1.1.3 |
| **RID / IMDG** <a id="rid-imdg"></a> | Zbiory przepisów odpowiednio dla kolejowego i morskiego przewozu towarów niebezpiecznych. W przewozie kombinowanym trzeba sprawdzić wymagania właściwe dla każdego odcinka. | ADR 1.1.4.2; przepisy RID i IMDG dla ich gałęzi |
| **Security / ochrona przewozu** <a id="security-ochrona-przewozu"></a> | Działania zapobiegające kradzieży, sabotażowi i nieuprawnionemu dostępowi. To coś innego niż mocowanie ładunku przed przesunięciem. | ADR 1.10 |

| **FL** <a id="fl"></a> | Oznaczenie typu pojazdu-cysterny używanego w ADR dla określonych przewozów cieczy lub gazów palnych. Nie jest ogólną nazwą każdego pojazdu ADR. | ADR 9.1.1.2 |
| **AT** <a id="at"></a> | Oznaczenie określonego typu pojazdu-cysterny lub pojazdu do przewozu materiałów niebezpiecznych w warunkach wskazanych w ADR. Nie zastępuje sprawdzenia, czy pojazd pasuje do danego ładunku. | ADR 9.1.1.2 |
| **EX/II i EX/III** <a id="ex-ii-i-ex-iii"></a> | Oznaczenia typów pojazdów przeznaczonych do przewozu określonych materiałów wybuchowych. Wymagany typ zależy od ładunku i warunków ADR. | ADR 9.1.1.2; 9.3 |
| **MEMU** <a id="memu"></a> | Mobilna jednostka do wytwarzania materiałów wybuchowych; specjalistyczna jednostka opisana w ADR. To nie jest zwykła ciężarówka do każdego ładunku. | ADR 1.2.1; część 9 |
| **DGSA / doradca ds. bezpieczeństwa** <a id="dgsa-doradca-ds-bezpieczenstwa"></a> | Osoba z wymaganym świadectwem, która wspiera przedsiębiorstwo w bezpiecznym przewozie towarów niebezpiecznych i monitorowaniu zgodności. Nie przejmuje automatycznie wszystkich obowiązków kierowcy ani firmy. | ADR 1.8.3 |
| **Zaświadczenie kierowcy ADR** (spotykane też: zaświadczenie ADR kierowcy) <a id="zaswiadczenie-kierowcy-adr"></a> | Dokument potwierdzający ukończenie wymaganego szkolenia i zdanie egzaminu dla określonego zakresu przewozu. Nie jest tym samym co świadectwo dopuszczenia pojazdu. | ADR 8.2.1; 8.2.2 |
| **Świadectwo dopuszczenia pojazdu** <a id="swiadectwo-dopuszczenia-pojazdu"></a> | Dokument wymagany dla określonych typów pojazdów i przewozów. Potwierdza dopuszczenie pojazdu w zakresie wskazanym w świadectwie; nie zastępuje dokumentów ładunku. | ADR 9.1.3 |
| **Dokument przewozowy** <a id="dokument-przewozowy"></a> | Dokument z wymaganymi informacjami o towarze i przewozie. Telefon do nadawcy ani faktura nie zastępują wymaganych wpisów ADR. | ADR 5.4.1 |
| **Instrukcja pisemna** <a id="instrukcja-pisemna"></a> | Wzór wskazówek dla załogi, co robić w razie wypadku lub zdarzenia. Załoga powinna mieć ją pod ręką i rozumieć jej treść. | ADR 5.4.3 |
| **Sztuka przesyłki** <a id="sztuka-przesylki"></a> | Gotowa jednostka opakowania z towarem, np. bęben, karton lub kanister, przygotowana do przewozu. | ADR 1.2.1 |
| **Opakowanie wewnętrzne** <a id="opakowanie-wewnetrzne"></a> | Opakowanie, w którym bezpośrednio umieszczono towar, znajdujące się wewnątrz opakowania zewnętrznego, gdy takie opakowanie jest stosowane. | ADR 4.1 |
| **Opakowanie zewnętrzne** <a id="opakowanie-zewnetrzne"></a> | Zewnętrzna osłona zestawu opakowań, która może chronić opakowania wewnętrzne podczas przewozu. | ADR 4.1 |
| **Opakowanie kombinowane** <a id="opakowanie-kombinowane"></a> | Zestaw, w którym jedno lub więcej opakowań wewnętrznych umieszczono w opakowaniu zewnętrznym. Musi spełniać właściwe wymagania dla danego towaru. | ADR 4.1.1 |
| **Kod opakowania** <a id="kod-opakowania"></a> | Oznaczenie typu opakowania i materiału, odczytywane według systemu ADR/ONZ. Sam kod nie dowodzi, że opakowanie jest właściwe dla każdego towaru. | ADR 6.1.2 |
| **Opakowanie certyfikowane UN** <a id="opakowanie-certyfikowane-un"></a> | Opakowanie przebadane i oznakowane zgodnie z właściwymi wymaganiami ONZ. Nadal trzeba sprawdzić, czy dopuszczono je do konkretnego towaru i sposobu użycia. | ADR 6.1.3; 4.1 |
| **Kod klasyfikacyjny** <a id="kod-klasyfikacyjny"></a> | Litera lub zestaw liter i cyfr doprecyzowujący rodzaj zagrożenia w obrębie danej klasy. | ADR część 2; tabela A, kolumna 3b |
| **Zagrożenie dodatkowe** <a id="zagrozenie-dodatkowe"></a> | Dodatkowy rodzaj zagrożenia, który również trzeba uwzględnić przy oznakowaniu i postępowaniu z towarem. | ADR 5.2.2; tabela A, kolumna 3b |
| **Grupa zgodności** <a id="grupa-zgodnosci"></a> | Oznaczenie używane przy klasyfikacji materiałów i przedmiotów wybuchowych, pomagające ustalić zgodność w określonych warunkach przewozu. | ADR 2.2.1.1.6 |
| **Kategoria transportowa** <a id="kategoria-transportowa"></a> | Kategoria przypisana towarowi w ADR, używana m.in. przy obliczeniach wyłączenia ilościowego. Nie jest tym samym co klasa zagrożenia. | ADR 1.1.3.6.3; tabela A, kolumna 15 |
| **Współczynnik mnożenia** <a id="wspolczynnik-mnozenia"></a> | Wartość używana w obliczeniach wyłączenia ilościowego dla określonych kategorii transportowych. Trzeba zastosować współczynnik z ADR, a nie wybrać go według uznania. | ADR 1.1.3.6.4 |
| **Całkowita ilość netto** <a id="calkowita-ilosc-netto"></a> | Ilość samej substancji lub materiału, bez masy opakowania, gdy przepis wymaga takiego sposobu liczenia. Zawsze sprawdź, czy ADR mówi o masie netto, objętości czy innej wielkości. | Właściwe przepisy ADR; np. 1.1.3.6 i część 3 |
| **Ilość ograniczona (LQ)** <a id="ilosc-ograniczona-lq"></a> | Ilość określona w kolumnie 7a tabeli A dla danej pozycji, która może umożliwiać zastosowanie wymagań ADR 3.4 po spełnieniu pozostałych warunków. | ADR 3.4; tabela A, kolumna 7a |
| **Ilość wyłączona (EQ)** <a id="ilosc-wylaczona-eq"></a> | Ilość określona zgodnie z ADR 3.5 dla danego towaru, przy której można zastosować szczególne wymagania dla EQ. To nie jest dowolnie mała ilość. | ADR 3.5; tabela A, kolumna 7b |
| **Kod ograniczenia tunelowego „(-)”** <a id="kod-ograniczenia-tunelowego"></a> | Zapis w kolumnie 15 tabeli A oznaczający, że dla tej pozycji nie przypisano kodu ograniczenia tunelowego. Nie uchyla innych znaków drogowych ani zakazów lokalnych. | ADR 3.2, tabela A, kolumna 15; 8.6 |
| **Tablica pomarańczowa bez numerów** <a id="tablica-pomaranczowa-bez-numerow"></a> | Tablica używana w określonych konfiguracjach ADR, bez numeru zagrożenia i numeru UN. To, czy tablica ma być numerowana, zależy od przewozu. | ADR 5.3.2 |
| **Nalepka dużego formatu** <a id="nalepka-duzego-formatu"></a> | Nalepka ostrzegawcza umieszczana na pojeździe, kontenerze lub innej jednostce, gdy wymaga tego ADR. Nie jest tym samym co nalepka na pojedynczym opakowaniu. | ADR 5.3.1 |
| **Znak LQ** <a id="znak-lq"></a> | Znak stosowany przy przewozie ilości ograniczonych, jeśli spełniono warunki ADR 3.4. Nie zastępuje wymaganych warunków pakowania. | ADR 3.4.7; 3.4.11 |
| **OVERPACK / opakowanie zbiorcze** <a id="overpack-opakowanie-zbiorcze"></a> | Zestaw kilku sztuk przesyłek połączonych w jedną jednostkę dla łatwiejszej obsługi. Jeśli oznakowanie wewnątrz nie jest widoczne, mogą być potrzebne dodatkowe oznaczenia na zewnątrz. | ADR 1.2.1; 5.1.2 |
| **Certyfikat pakowania kontenera/pojazdu** <a id="certyfikat-pakowania-kontenera-pojazdu"></a> | Dokument potwierdzający wykonanie wymaganych czynności przy pakowaniu kontenera lub pojazdu w przypadkach objętych ADR. Sprawdź, czy jest wymagany dla konkretnego przewozu. | ADR 5.4.2 |
| **Transport kombinowany** <a id="transport-kombinowany"></a> | Przewóz, w którym ładunek pokonuje trasę różnymi środkami transportu, np. statkiem i ciężarówką. Każdy odcinek może mieć własne wymagania. | ADR 1.1.4.2; 1.1.4.5 |
| **RID** <a id="rid"></a> | Przepisy dotyczące międzynarodowego przewozu kolejowego towarów niebezpiecznych. | ADR 1.1.4.2; RID |
| **IMDG Code** <a id="imdg-code"></a> | Międzynarodowy kodeks dotyczący przewozu towarów niebezpiecznych drogą morską. Dokumenty morskie nie zwalniają automatycznie z wymagań drogowych. | ADR 1.1.4.2; IMDG Code |
| **Towary dużego ryzyka** <a id="towary-duzego-ryzyka"></a> | Towary, których kradzież lub niewłaściwe użycie może prowadzić do poważnych skutków. ADR określa listę i progi; nie każdy towar niebezpieczny automatycznie należy do tej grupy. | ADR 1.10.3.1.2 |
| **Plan ochrony** <a id="plan-ochrony"></a> | Plan opisujący środki zapobiegania kradzieży, sabotażowi i nieuprawnionemu dostępowi dla przewozów, w których jest wymagany. | ADR 1.10.3.2 |
| **Zabezpieczenie ładunku / mocowanie** <a id="zabezpieczenie-ladunku-mocowanie"></a> | Pasy i inne środki, które ograniczają przesuwanie lub przewrócenie ładunku. To inne zadanie niż ochrona przed kradzieżą. | ADR 7.5.7 |
| **Wspólny załadunek** <a id="wspolny-zaladunek"></a> | Umieszczanie różnych towarów razem w pojeździe. Niektóre połączenia są zabronione lub wymagają rozdzielenia; trzeba sprawdzić właściwy przepis. | ADR 7.5.2 |
| **Zanieczyszczenie po wycieku** <a id="zanieczyszczenie-po-wycieku"></a> | Pozostałość substancji, która dostała się na pojazd lub do przestrzeni ładunkowej. Może wymagać oczyszczenia przed ponownym załadunkiem. | ADR 7.5.8 |

| **Pojazd EX/III** <a id="pojazd-ex-iii"></a> | Inny typ pojazdu do przewozu określonych materiałów wybuchowych, spełniający wymagania odpowiedniej kategorii ADR. | ADR 9.3 |

| **Szkolenie stanowiskowe ADR 1.3** <a id="szkolenie-stanowiskowe-adr-1-3"></a> | Szkolenie dostosowane do obowiązków pracownika uczestniczącego w przewozie towarów niebezpiecznych. Nie jest tym samym co zaświadczenie kierowcy ADR. | ADR 1.3 |
| **Szkolenie kierowcy ADR** <a id="szkolenie-kierowcy-adr"></a> | Szkolenie i egzamin wymagane dla kierowców określonych przewozów. Zakres zależy od rodzaju przewozu i specjalizacji wymaganych przepisami. | ADR 8.2 |

| **Przegląd gaśnicy** <a id="przeglad-gasnicy"></a> | Kontrola i obsługa sprzętu gaśniczego zgodnie z właściwymi wymaganiami. Sprawdzaj stan, oznaczenia i termin, nie tylko samą obecność gaśnicy. | ADR 8.1.4 |
| **Wyposażenie ochronne** <a id="wyposazenie-ochronne"></a> | Sprzęt wskazany dla konkretnego przewozu, który pomaga ograniczyć określone ryzyko. Rękawice, okulary, latarka i kamizelka pełnią różne funkcje. | ADR 8.1.5; instrukcje pisemne 5.4.3 |
| **Awaria** <a id="awaria"></a> | Zdarzenie, które uniemożliwia bezpieczną kontynuację jazdy lub może wpływać na bezpieczeństwo przewozu. Kierowca powinien zabezpieczyć miejsce i działać według procedur. | ADR 5.4.3; 8.4, gdy ma zastosowanie |
| **Wyłączenie** <a id="wylaczenie"></a> | Przepis, który usuwa lub ogranicza określone wymagania tylko w ściśle opisanych warunkach. Zawsze sprawdź zakres wyłączenia, zamiast zakładać, że cały ADR przestaje obowiązywać. | ADR 1.1.3; 3.4; 3.5 |
| **Przepis szczególny** <a id="przepis-szczegolny"></a> | Dodatkowa reguła przypisana do określonego towaru w tabeli A. Może ograniczać lub uzupełniać ogólne zasady przewozu. | ADR 3.3; tabela A, kolumna 6 |
| **Tabela A** <a id="tabela-a"></a> | Wykaz towarów niebezpiecznych w ADR. W poszczególnych kolumnach podaje m.in. numer UN, klasę, wymagania pakowania i kod tunelowy. | ADR 3.2.1 |
| **Kolumna 15 tabeli A** <a id="kolumna-15-tabeli-a"></a> | Pole zawierające m.in. kategorię transportową i kod ograniczenia tunelowego dla danej pozycji. Trzeba czytać właściwą część kolumny dla danego pytania. | ADR 3.2.1 |
| **Karta charakterystyki** <a id="karta-charakterystyki"></a> | Dokument dostawcy opisujący zagrożenia i bezpieczne obchodzenie się z produktem. Nie zastępuje dokumentu przewozowego ADR, gdy ten jest wymagany. | Przepisy dotyczące chemikaliów; ADR 5.4.1 dla dokumentu przewozowego |
| **SDS** <a id="sds"></a> | Skrót angielskiej nazwy karty charakterystyki (Safety Data Sheet). To dokument informacyjny o produkcie, a nie automatyczny zamiennik dokumentacji przewozowej ADR. | Przepisy dotyczące chemikaliów; ADR 5.4.1 |
| **Znak zagrożenia środowiskowego** <a id="znak-zagrozenia-srodowiskowego"></a> | Znak wymagany dla niektórych towarów, gdy spełnione są kryteria ADR. Nie należy go stosować ani pomijać wyłącznie na podstawie wyglądu produktu. | ADR 5.2.1.8; 5.3.6 |
| **Kontener** <a id="kontener"></a> | Jednostka ładunkowa używana w transporcie, która musi spełniać odpowiednie wymagania ADR dla przewozu danego towaru. | ADR 1.2.1; część 7 |
| **Kontrola drogowa** <a id="kontrola-drogowa"></a> | Sprawdzenie dokumentów, oznakowania, wyposażenia i zgodności przewozu przez uprawnione służby. Kierowca powinien przedstawić wymagane dokumenty i nie zgadywać brakujących danych. | ADR 1.8.1; przepisy krajowe |
