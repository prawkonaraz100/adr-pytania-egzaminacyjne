# ADR podstawowy

Aktywny obszar pracy. Pytania (własne i zweryfikowane) będą zapisane w pliku questions.jsonl. Na 22.10.2026 plik celowo jest pusty — **nie mamy jeszcze zatwierdzonych rekordów**.

- Program i cele: ../docs/PROGRAM-PODSTAWOWY.md
- Standard: ../docs/STANDARD-PYTAN.md
- Źródła: ../docs/ZRODLA.md
- Walidacja: python scripts/validate.py (uruchamiane w katalogu głównym)
- Egzamin państwowy: 30 pytań, 60 minut, minimum 20 poprawnych; symulacja dopiero po zatwierdzeniu dostatecznej liczby pytań.

Wariant A/B/C nie oznacza publicznie dostępnego urzędowego klucza. To autorska baza do ćwiczeń.
