# ADR specjalistyczny — cysterny

Status: **NIE ROZPOCZĘTO**. Oddzielny etap po ukończeniu banku i Quality Gate kursu podstawowego.

Kurs specjalistyczny w zakresie cystern ma własny urzędowy program i odrębny egzamin (18 pytań, 40 minut, próg 12 poprawnych według Dz.U. 2024 poz. 964). Nie kopiujemy ani nie mieszamy bezmyślnie pytań z podstawowego. Tu powstanie osobna mapa programu, źródeł i zbioru pytań.
